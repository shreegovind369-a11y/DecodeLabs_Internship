# Decodelabs – Data Cleaning and Preparation

## Project Overview
This project is part of my Data Analytics Internship at Decodelabs (The Code Lab).

Project 1 focuses on transforming raw and inconsistent data into clean, structured, and reliable data using Microsoft Excel.

## Project Objective
The main objective is to improve data quality and data integrity through data cleaning and preparation techniques.

## Tools Used
- Microsoft Excel

## Project Workflow

### 1. Data Inspection
- Understand the raw dataset.
- Identify missing values, duplicates, and inconsistencies.

### 2. Strategic Imputation
- Identify missing values.
- Apply appropriate methods to handle missing data.

### 3. Integrity Audit
- Check data accuracy and consistency.
- Identify and remove duplicate records where appropriate.

### 4. Speak One Language
- Standardize text formats.
- Remove unnecessary spaces.
- Maintain consistent naming conventions.

- Raw Dataset

## Key Learning Outcomes
- Data cleaning using Excel.
- Handling missing values and duplicates.
- Text standardization using Excel functions.
- Data quality checking and documentation.
