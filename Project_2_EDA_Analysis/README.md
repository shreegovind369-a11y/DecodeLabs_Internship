# Exploratory Data Analysis (EDA) Using Microsoft Excel

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a sales dataset using Microsoft Excel. The objective is to clean, organize, analyze, and interpret the data to identify meaningful patterns, trends, and business insights.

## Project Objectives
- Understand the structure and quality of the dataset.
- Identify and handle missing values and duplicate records.
- Perform descriptive statistical analysis.
- Detect potential outliers using the IQR method.
- Analyze sales performance and customer order patterns.
- Identify trends and generate meaningful insights through data visualization.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Formulas & Functions
- Excel Charts and Data Visualization

## Dataset Description
The dataset contains 1,200 records and 14 columns related to customer orders and sales transactions.

Key attributes include:
- Order ID
- Date
- Customer ID
- Product
- Quantity
- Unit Price
- Payment Method
- Order Status
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

## Project Workflow

### 1. Data Cleaning & Preparation
- Checked for missing values.
- Identified duplicate records.
- Reviewed data formats and consistency.
- Prepared the dataset for analysis.

### 2. Descriptive Statistical Analysis
- Calculated Mean and Median.
- Calculated total revenue.
- Identified minimum and maximum sales values.
- Analyzed order quantities.

### 3. Outlier Detection
- Applied the Interquartile Range (IQR) method.
- Calculated Q1, Q3, IQR, lower limit, and upper limit.
- Identified potential outliers in the Total Price column.

### 4. Exploratory Data Analysis
- Product-wise sales and revenue analysis.
- Payment method analysis.
- Order status analysis.
- Referral source analysis.
- Year-wise and monthly sales trend analysis.
- Quantity and total price relationship analysis.

### 5. Data Visualization
Created Excel charts and Pivot Table summaries to present findings and compare different business metrics.

## Key Learnings
- Practical experience in data cleaning and preparation.
- Understanding descriptive statistics and outlier detection.
- Improved Excel and Pivot Table skills.
- Ability to identify sales trends and interpret business data.
- Developed analytical thinking and data interpretation skills.

This project provided practical experience in Exploratory Data Analysis using Microsoft Excel. It helped transform raw sales data into meaningful information and develop a better understanding of data-driven business analysis.
